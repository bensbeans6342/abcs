📖 How to Use This Book

Welcome to Ancient Civilizations ABCs! This is how to use it:

  • Select Letters: Use the dropdown menu at the top to jump to any letter immediately!
  • Turn Pages: Use the Previous and Next buttons underneath the page to read in order!
  • Theme: Toggle between light and dark modes anytime using the button at the bottom.
